Use case · Sentry Mode

Review Sentry Mode events from every saved angle.

A Sentry event can include several camera files. Open your SentryClips folder once, choose an event, and review its available views together on a shared timeline.

Open SentryClips →Folder setup guide

Find the event you need

In Chrome or Edge, select your TeslaCam folder or the SentryClips folder directly. The viewer lists the events it finds so you can move between recordings without opening each MP4 by hand. If the drive contains other TeslaCam folders, use the event filters to focus on Sentry recordings.

Keep the cameras in sync

Select an event to play its available front, rear, and side camera clips together. Use the timeline to pause or seek to a moment, and choose a layout that makes the important angle easier to inspect. The viewer can only display camera files that were saved for that event.

Save a useful frame or segment

When you need a still image, use the screenshot control. For video, mark the part of the timeline you want and open the export controls. Export options and usage limits depend on the viewer's access settings; see the export guide before relying on a particular format.

What to check if footage is missing

Confirm the selected folder contains event folders and MP4 files. Try selecting the main TeslaCam folder if a clip folder appears empty. Keep the USB drive connected while reviewing the recordings. A missing camera angle usually means its corresponding file is absent from the event.

Common questions

Can I review Sentry clips without uploading them?

Yes. The browser reads the video files from the folder you choose. Optional map and weather features may use location data with external services.

Why do I see fewer than four cameras?

The viewer shows the camera files available in that event. Check the event folder if a view is missing.

Will this work in Safari?

No. Use Chrome or Edge for the folder access feature used by this viewer.
