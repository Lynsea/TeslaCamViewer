Use case · Capture and export

Keep the part of a dashcam recording that matters.

Find the moment in a Tesla dashcam or Sentry event, capture a still frame, or mark a shorter range for video export. The viewer shows the export choices available to your session.

Start with the right event and angle

Select your TeslaCam folder in Chrome or Edge, then choose an event from the sidebar. Use the timeline and playback speed controls to find the moment. Switch layouts if you need to focus on a particular camera or include several angles in a single view.

Capture a screenshot

Pause at the frame you want and use the screenshot control. A still image is useful when you need to reference one point in time without sharing a full recording. Check the saved image before relying on it: the chosen layout and available cameras determine what appears.

Mark a shorter video range

Move the playhead to the start of the useful section and set an In point. Move to the end and set an Out point. Then open the export control and review the available camera and format options. The viewer supports video export workflows, but options and limits can vary with access settings and browser capabilities.

Check the result before sharing

Play the exported file and confirm that it includes the right time range, camera views, and audio or overlays if you expected them. If you need to reduce location or timestamp details, inspect the privacy options available in the export interface. Do not assume an export has removed data until you check the finished file.

Common questions

Can I export only part of an event?

Yes. Set In and Out points around the segment, then review the export controls. Availability may depend on your current access level.

Which video formats are available?

The viewer includes MP4 and WebM export paths. Confirm the format offered for your recording and browser in the export dialog.

Why is an export control unavailable?

Load an event first. Some export tools also have usage or license limits; the viewer displays the available options for the current session.
