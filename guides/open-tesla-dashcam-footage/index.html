Setup guide

How to view Tesla dashcam and Sentry Mode footage.

You can review TeslaCam recordings without opening every MP4 separately. This guide shows how to find the right folder, open it in the browser viewer, and check common playback problems.

Open the viewer →

Before you start

You need access to the drive or folder holding your TeslaCam recordings and a current version of Chrome or Edge. The viewer uses the browser's folder access feature, which Safari and Firefox do not support. If you use the hosted viewer, open it over HTTPS; if you run a local copy, use a local web server.

Your video files are read from the folder you select. They are not uploaded to the site. Some optional features, including maps and weather, can contact external services with location information.

Find your TeslaCam folder

On your connected drive or computer, look for a folder named TeslaCam. It may contain SavedClips, SentryClips, and RecentClips. You can choose the main TeslaCam folder to browse the available recording types together, or choose one of its clip folders directly.

  • SavedClips contains saved dashcam events.
  • SentryClips contains events recorded by Sentry Mode.
  • RecentClips contains recent rolling footage that may change as the drive is used.

The folders and camera files you see depend on what your vehicle recorded. A missing angle in the viewer can mean that the corresponding video file is not present in that event.

Open the footage in the viewer

  1. Open the TeslaCam viewer in Chrome or Edge.
  2. Select “Select TeslaCam Folder” in the sidebar.
  3. Choose your TeslaCam folder or a folder containing the recordings, then allow the browser to read it.
  4. Pick an event from the sidebar. The viewer loads the camera videos available for that event.

Use the timeline to seek through the event. You can change the layout, pause, step through frames, or switch to another recording. The features page explains the main controls and optional tools.

For a specific task, see the guides to Sentry Mode events, dashcam recordings, and screenshots and exports.

If no recordings appear

First check that the selected folder actually contains TeslaCam video files. If you selected a parent folder, try the TeslaCam folder itself; if you selected an empty clip folder, try the main TeslaCam folder. Make sure the USB drive is still connected and readable.

If the folder picker is missing or cannot open, check that you are using Chrome or Edge. If an event appears but its video does not play, try another event to see whether the issue is limited to a particular MP4 file. Some older recordings do not contain the telemetry used by optional overlays; the video can still be viewed without that data.

Questions people ask

Can I view Tesla Sentry Mode footage online?

Yes, you can open the browser viewer online and select a local SentryClips folder. The video files themselves remain on your device.

Do I need to upload my dashcam files?

No. Choose the folder in the browser. The viewer reads the files locally.

Why are some camera views missing?

The viewer can only show camera files present in the selected event. Check the event folder for its MP4 files and try another event.
